# L0406 — an operator is written over a type that has no instance of its trait

Every operator is a trait method, which `docs/specs/operators.md` states.
`+` is `Add`, `-` is `Sub`, `*` is `Mul`, `/` is `Div`, `%` is `Rem`, prefix `-` is `Neg`, the four
comparisons are `Ord`, and `==` and `!=` are `Eq`.
A type is written with one of them exactly where it has that trait's instance, and nowhere else.

```text
error[L0406]: `User` has no `Eq`, so `==` is not written over it
```

`Int` has every one of the eight, `String` has `Eq` and `Add`, and `Bool` has `Eq`.
A type you declare gets an operator the one way any type gets one: by writing that trait's
instance, as `docs/specs/traits.md` states.

Until it has one, write what the values hold instead: `left.id == right.id`, where `id` is an
`Int`.

Nothing is equal by being the same object, because a Bux value has no identity to be equal by.
Two values are equal by what they hold, and only where their type says so.
