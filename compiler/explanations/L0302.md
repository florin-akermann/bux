# L0302 — a name is already in scope

A binding never hides a name that is already in scope.
Where a language allows it, reading a name means working out which definition is the nearest one.
A search for the name then finds uses that belong to something else entirely.

Bux refuses the shape instead.
Rename the inner one for what it is: the narrower thing usually has the more specific name.

The prelude counts as being in scope, so a declaration named `Ok` or `String` is this error too.
So is a loop binding that reuses a parameter's name.
So is a parameter that reuses the name of a function the file declares.
