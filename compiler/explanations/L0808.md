# L0808 — the body of `receive` is not one `match` on the message

The body of `receive` is one `match` on the message, and nothing else.

```
process Counter {
    fn start(initial: Int) -> Int {
        initial
    }

    fn receive(total: Int, message: Counted) -> Next<Int> {
        match message {
            Add(amount) => Continue(total + amount)
            Stop => Done
        }
    }
}
```

A reader finds each message that the process answers in the arms of the `match`.
Other work in the body would hide that list.
Move the work into a function of the module, and call it from an arm.
