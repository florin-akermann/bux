# L0805 — a function of a process declares a type parameter

A process has one type of state and one type of message.

```
process Counter {
    fn start<T>() -> Int {
        0
    }
    ...
}
```

A type parameter on `start` or `receive` gives the process more than one type of either.
A handle is `Process<Message, State>`, and it names one of each.
Remove the type parameter, and write the types out.
