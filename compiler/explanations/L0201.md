# L0201 — an import is out of order

Imports come first in a file, before every declaration, sorted by the module they name.

```text
error[L0201]: `import io` is written after a declaration
```

A new import then has one place to go, and is never a diff that also moves the others.
Two files that import the same modules import them in the same order.

```text
import files

import io

fn main(arguments: List<String>) -> Int {
    0
}
```

Order is checked and never rewritten.
`lumen fmt` repairs whitespace, which is nobody's decision.
Where an import belongs is said rather than rewritten.
