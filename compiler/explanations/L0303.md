# L0303 — a declaration is written above something that uses it

A file reads top down: the reader meets the intent before the detail.
A declaration is therefore written above what it uses, and a helper below the thing it helps.

```text
error[L0303]: `joined` is written above `greeted`, which uses it
```

Run `bux fmt <file>`, which moves it below the last declaration that uses it.

```text
fn greeted(who: String) -> String {
    joined(who)
}

fn joined(who: String) -> String {
    "hello, " + who
}
```

Two declarations that use each other are written either way, because no order undoes a cycle.
A declaration that uses itself is not above itself, so recursion is never reported.
`bux fmt` keeps two declarations that use each other in the order they are written.
