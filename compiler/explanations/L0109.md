# L0109 — `:=` does not bind a name

A name is bound with `let` or with `var`, and `=` joins the name to its value.

```
fn counted() -> Int {
    total := 0
    total
}
```

`:=` is not part of Bux, so this statement binds nothing.
Write `let` where the name never changes:

```
fn counted() -> Int {
    let total = 0
    total
}
```

Write `var` where the name is assigned to later:

```
fn counted() -> Int {
    var total = 0
    total += 1
    total
}
```

The keyword says what the name is, and `=` has the same job in each of the two.
A bare `=` after that changes a `var`, and nothing else.
