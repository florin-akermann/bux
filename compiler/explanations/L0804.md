# L0804 — a process declares a function after `receive`

A process declares `start`, then `receive`, and nothing else.

```
process Counter {
    fn start(initial: Int) -> Int {
        initial
    }

    fn receive(total: Int, message: Counted) -> Next<Int> {
        match message {
            Add(amount) => Continue(total + amount)
            Stop => Done
        }
    }
}
```

A third function in the process has no place in the shape.
Move it out of the process, and write it as a function of the module below the process.
`receive` calls it from an arm of its `match`.

A process has one shape, so a reader knows where its state and its messages are.
The compiler checks the shape before it infers a type, so the message names the broken part.
`docs/specs/concurrency.md` states the shape in full.
