# L0811 — a process holds a foreign reference

A process holds values only, and a value of an `extern` type is a foreign reference.

```
process Reader {
    fn start(file: File) -> Int {
        0
    }

    ...
}

extern type File = "java.io.File"
```

A process holds what `start` takes, its state, and its message.
`File` names a Java object, which has identity and can change.
A process that held one would share that object with the function that gave it.
Keep the foreign reference in the function that reaches it, and give the process a value.
A path, a count, or a line of text is a value that the process can hold.
