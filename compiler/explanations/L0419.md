# L0419 — a parameter of a trait's method states no type

A trait declares what a type can do, and a declaration with no body has nothing to infer from.

```text
error[L0419]: `other` states no type, and a signature is never inferred
```

A signature is the first line and no more, so a type left out of one is a type nothing settles.

The trait writes each of them:

```
trait Eq<T> {
    fn is_equal(one: T, other: T) -> Bool
}
```

An instance writes them too, because every function writes its whole signature:

```
instance Eq<Point> {
    fn is_equal(one: Point, other: Point) -> Bool {
        one.across == other.across
    }
}
```

A method that gives nothing back writes no `->`, which is the one thing a signature may omit.
