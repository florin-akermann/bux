# L0701 — a text or a name takes more than 65535 bytes

A compiled class keeps each text and each name once, in a table of constants.
Two bytes write the length of each entry, so one entry holds 65535 bytes at most.
Most characters take one byte, and some take two or three.
So a text of 21846 characters can be too long.

The compiler does not cut the text, because the program would then write a different text.
So it refuses the text and names the function or the type that holds it.

```
fn banner() -> String {
    "... a text of 70000 characters ..."
}
```

## What to do

Split the text into parts, and join the parts with `+`.
Each part is then one entry of its own, and each entry is within the limit.
If a name is too long, give it fewer characters.

## When it is raised

`lumen build`, `lumen run`, and `lumen test` raise it when they write the classes of a program.
`lumen check` writes no class, so it does not raise it.
