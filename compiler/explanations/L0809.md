# L0809 — an arm of `receive` is not one call or one name

Each arm of the `match` in `receive` is one call or one name.

```
Add(amount) => if amount > 0 {
    Continue(total + amount)
} else {
    Done
}
```

An `if`, a block, or a second `match` in an arm is work, and work has a name.
Move it into a function of the module, and call it:

```
Add(amount) => added(total, amount)
```

The arms then read as a list of the messages and the name of what each one does.
