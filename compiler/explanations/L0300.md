# L0300 — there is nothing of that name

Every name in a Lumen file must have a definition the compiler can point at.
A definition is a declaration in the same file, a prelude name, or a module the file imports.
Nothing else is in scope: Lumen has no implicit global and no unqualified import.

A name after a `.` is not looked up this way.
`user.name` looks `name` up in the type of `user`, not in the file.
`io.print` looks `print` up in the module `io`, so neither can be reported here.

The usual causes are a misspelling and a declaration that was never written.
The third is a name used outside the block that binds it.
A binding is in scope from the statement after it to the end of its block.
A loop binding and a pattern's bindings reach no further than the body they belong to.
