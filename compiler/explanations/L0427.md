# L0427 — a derive of an extern type

A derive writes an instance by reading what a type holds.

```text
extern type Path = "java.nio.file.Path"

derive Eq for Path
```

An extern type holds nothing a Lumen declaration wrote: what it holds is the Java class it names,
and the compiler has neither loaded that class nor any business reading it.
So there is nothing for `Eq`, `Ord`, `Hash`, or `Show` to be written over.

An `instance` written by hand is the answer, over `extern` declarations that say how.
That is what makes a value of a Java class comparable, hashable, or showable: a trait said how,
rather than the object model saying it for every type at once.

`docs/design.md` section 17 states what a program may do with a Java object, and
`docs/specs/interop.md` states the declaration.
