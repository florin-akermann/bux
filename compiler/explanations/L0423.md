# L0423 — a call with its first argument in front names its arguments

`maybe.or(fallback)` is the call `or(maybe, fallback)`, written with its first argument in front.

```
fn rename(from: String, to: String) -> String {
    from + to
}
```

`old.rename(to: new)` names one of the two arguments and not the other.
The receiver is an argument, and a dot is not a place to write a name.
There is nowhere for `from:` to go.
A call names all of its arguments or none of them, which `docs/specs/arguments.md` states.

The call is written plainly when it names them:

```
rename(from: old, to: new)
```

`rename` gives two of its parameters one type, so a call of it has to name its arguments.
This function is therefore never written with its first argument in front.
A function whose parameters hold each other apart by type is written either way.
A call of one in front form passes its values in order.
