# L0807 — `receive` does not take a state and a message

`receive` takes two values: the state, and then one message.

```
fn receive(total: Int, message: Counted) -> Next<Int> {
```

The first parameter holds the state that `start` gave, or that the last message left.
The second parameter holds the message that the mailbox gave.
A `receive` with one parameter, or with three, has no place for one of them.
