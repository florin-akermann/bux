# L0801 — a process is called or held as a value

A process is started with `spawn`, and never called as a function or held as a value.

```
fn main(arguments: List<String>) -> Int {
    _ = Counter(10)
    0
}
```

The call reads as a call of a function, but `Counter` is a process.
Write `spawn` before the call:

```
counting := spawn Counter(10)
```

One spelling tells a reader where a new process starts.
A call that starts a thread without a word to say so would hide that.
