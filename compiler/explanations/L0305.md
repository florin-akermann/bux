# L0305 — an assignment names something other than a `var` binding

Data is immutable by default and mutation is explicit, which `var` is the word for.

```
fn count() -> Int {
    let total = 0
    total = 2
    total
}
```

`let total = 0` binds a name that is never assigned to again.
Writing `total = 2` below it takes back what the `let` promised the reader two lines above.

`var` says at the binding that the name changes:

```
fn count() -> Int {
    var total = 0
    total = 2
    total
}
```

Where nothing should change, bind a second name instead:

```
fn count() -> Int {
    let total = 0
    let doubled = total + total
    doubled
}
```

A parameter, a `for … in` binding, and a name a pattern binds are all bindings that never change.
So is a constructor, which names a way to build a value rather than a place to put one.
`Marker = Marker` has nowhere to write, and it is refused rather than compiled into nothing.
