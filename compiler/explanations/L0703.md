# L0703 — the compiler did not write a function

The compiler checks each method that it writes before it writes the class.
A jump must land on a place that the method holds.
Two paths into one place must hold the same number of values.
If one of these checks fails, the compiler is at fault, and not the program.

The compiler does not write a class that it knows is wrong.
It refuses the program, and the message names the function and what went wrong.

## What to do

This is a defect of the compiler.
Report it with the program that shows it, and include the message.
Until the defect is fixed, a change to the shape of the function can go around it.

## When it is raised

`bux build`, `bux run`, and `bux test` raise it when they write the classes of a program.
`bux check` writes no class, so it does not raise it.
