# L0100 — the grammar expected one thing and the source wrote another

The parser reads a program by the grammar in `docs/specs/grammar.md`.
This is what it says when the next thing it reads cannot continue what it was reading.
The message names what the grammar wanted, and what stood there instead.

Read the line the carets point at, and the line above it.
The cause is usually a bracket left open, a comma left out, or a keyword used as a name.

One case is worth naming: `fn (x)` is refused because Bux has no anonymous functions.
Every function has a name, so that the reader always has a word to search for.
