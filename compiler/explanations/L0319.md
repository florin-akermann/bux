# L0319: two tests of a module have one name

`bux test` names a test that did not hold by its module, its line, and its name.
A reader looks for the test by its name, so two tests of one module with one name are refused.

```text
test "adds" {
    1 + 1 == 2
}

test "adds" {
    2 + 2 == 4
}
```

The refusal points at the name of the second test.
Give each test a name that says what it holds:

```text
test "adds one and one" {
    1 + 1 == 2
}

test "adds two and two" {
    2 + 2 == 4
}
```

Two modules can each have a test with the same name, because the report names the module too.

`docs/specs/testing.md` states the name of a test and the report of `bux test`.
