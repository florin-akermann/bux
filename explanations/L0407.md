# L0407 — a divisor is written as zero

`/` and `%` give back an `Option<Int>` because a zero divisor has no answer.
Where the divisor is written out and that zero is what it is, there is nothing left to find out.

```
fn go(total: Int) -> Option<Int> {
    total / 0
}
```

This always gives `None`, whatever `total` holds.
A branch taken every time is not worth compiling, so the program is refused where it is written.

The rule is narrow on purpose: it is the zero that is written, not one worked out.

```
fn go(total: Int, count: Int) -> Option<Int> {
    total / count
}
```

Nothing here is refused.
`count` may well be zero when it runs, and that is what the `Option` in the type is for.

Where a zero divisor was not what was meant, divide by something else.
Where the `None` was what was meant, write it: `None` says it directly, and says it shorter.
