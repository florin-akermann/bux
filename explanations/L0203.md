# L0203 — a declared name is an initial

`f` tells a reader the shape of the code and nothing about the domain.

```
fn f(count: Int) -> Int {
```

A declared name is a name another file can write, so it is worth a word.
Two characters are enough for one: `go` and `or` are words, and `f` is an initial.

The word measured is the one canonical form spells, not the characters you wrote.
`_a` names the one-letter word `a`, and `__` names no word at all, so both are initials too.

A local binding is private to the body it is written in, so this rule is not about one.
A tight loop may bind `i` and say everything the reader needs.

## A type parameter is exempt

```
fn identity<T>(value: T) -> T {
```

`T` names no domain concept.
It stands for whatever type a call supplies, and `T` is how that is written.

`docs/specs/naming.md` states the rules.
