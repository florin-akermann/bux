# L0605 — the file is no Bux source, because its name does not end in `.bx`

A Bux source is a file whose name ends in `.bx`, and the name before `.bx` names the module.
An import reads `<module>.bx` and no other name, and a command takes no file of another name.

```text
bux check notes.lm
```

`notes.lm` is refused before anything in it is compiled, whatever text the file holds.
The diagnostic points at the start of the file, because the name is what is wrong, not the text.

## What to do

Rename the file so that its name ends in `.bx`: `notes.lm` becomes `notes.bx`.
An import of `notes` then finds it too.

## When it is raised

`bux fmt`, `bux check`, `bux build`, `bux run`, `bux test`, and `bux api` raise it for a file.
A directory is a package, which `bux check` and `bux build` take, and it is not refused here.
A path that names nothing is reported without a code, as a file that cannot be read.
