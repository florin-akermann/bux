# L0301 — a name is declared twice

One name has one definition.
A module that declares a name twice has written two definitions for one word.
Every use of it would then have to be read twice before it could be understood.

Bux has no overloading, so the two cannot be told apart by what they take or return.
Give one of them a name that says how it differs; that name is what a reader searches for.

Types and values are named separately, so `type UserId = UserId(Int)` is not this error.
The type and the constructor are found in different places.
The compiler never has to guess which of the two was meant.
