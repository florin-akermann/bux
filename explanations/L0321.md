# L0321 — the binding or the parameter is read by nothing

Every name that a program introduces is read at least once, or it is refused.
This holds for a `let`, a `var`, a `for` binding, a name that a pattern binds, and a parameter.

```
fn shipped(order: Order) -> Int {
    let weight = order.items * 2
    order.items
}
```

Nothing reads `weight`, so the binding is refused at the name.
A read is a use of the name as a value.
An assignment, `+=` included, is not a read, so a `var` that is only assigned is refused too.

Write `_ =` where only the effect of a value is necessary:

```
fn saved(text: String) -> () {
    _ = files.write("seen.txt", text)
}
```

Write `_` for a value that a pattern or a loop does not need:

```
fn counted(values: List<Int>) -> Int {
    var count = 0
    for _ in values {
        count += 1
    }
    count
}
```

Remove a parameter that nothing reads, together with its arguments at each call.
The rule does not hold a parameter of a signature that the function does not choose.
These are the `arguments` of `main`, each instance method parameter, and `start` and `receive`.

A hole reads every name in scope where it is written.
The reason is that the code that the hole stands for can read any of them.
