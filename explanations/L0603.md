# L0603 — an example does not hold

`bux test` ran an example the module states, and it was not `true`:

```
// example: or(shared(total: 17, people: 5), 0) == 4
fn shared(total: Int, people: Int) -> Option<Int> {
    total / people
}
```

`17` divided among `5` is `3`, so the example states what the function does not work out.

## What to do

One of the two is wrong, and which one is the author's to say.

Correct the example where the function is right.
Correct the function where the example is what the function was supposed to do.

## When it is raised

`bux test` alone raises it, because it is the only command that runs an example.

`bux build` asks only that an example is stated, not that it holds.
Running one needs a JDK, and building a module does not.

Every example that did not hold is reported, rather than the first.
A run is how a reader learns what is wrong, and a list of one would not be that list.
