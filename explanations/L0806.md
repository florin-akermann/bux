# L0806 — a function of a process leaves a type unwritten

A process writes the type of each parameter and the type of the result of each function.

```
process Counter {
    fn start(initial) -> Int {
        initial
    }
    ...
}
```

Inference fills an unwritten type from the calls of a function.
Nothing in the source calls `start` or `receive`, because the process calls them itself.
So nothing could fill the type, and the process writes it:

```
    fn start(initial: Int) -> Int {
```
