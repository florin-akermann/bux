# L0426 — that is no Java name

An `extern` states the Java member it reaches, in quotes.

```text
extern field out() -> PrintStream = "java.lang.System.out"
extern method to_path(file: File) -> Path = "toPath"
```

A Java name is its segments with a dot between two of them, and each segment is a name: it begins
with a letter, a `_`, or a `$`, and holds letters, digits, `_`, and `$` after that.

A `field` and a `static` name at least two segments, because the last of them is the member and
the rest is the class it is on.
A `type` names at least one.
A `method` names exactly one, because the receiver's type already says which class it is on, and
a `new` names none at all, because its result already says.

Whether the class or the member is there is the JVM's answer and not the compiler's: nothing is
loaded to refuse it against, which `docs/specs/interop.md` states.

`docs/specs/interop.md` states the declaration and what each kind names.
