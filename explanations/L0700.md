# L0700 — a function is too large to compile as one function

The compiler writes each function as one method, and a method has two limits.
Its code holds 65535 bytes at most.
A jump inside it reaches 32767 bytes forward or back at most.
A function that is past one of these limits cannot be written as one method.

The compiler does not cut the code and does not change a jump to fit.
Both would give a program that does not do what its source says.
So the compiler refuses the function and names it.

## What to do

Split the function into smaller functions.
A long body of statements often holds parts that each do one thing, and each part can be a function.
A long `if` or `match` can give each of its branches to a function of its own.

## When it is raised

`bux build`, `bux run`, and `bux test` raise it when they write the classes of a program.
`bux check` writes no class, so it does not raise it.
