# L0800 — `spawn` starts something that is not a process

`spawn` starts a process, and nothing else.

```
fn main(arguments: List<String>) -> Int {
    _ = spawn counted()
    0
}
```

`counted` is a function, so `spawn` cannot start it.
A process is declared with `process`, and `spawn` names it with the values that `start` takes:

```
let counting = spawn Counter(10)
```

The name of a process alone is refused too, because `spawn` passes values to `start`.
Write the call, with empty parentheses where `start` takes nothing: `spawn Counter()`.

A process of another module is reached through the module's name: `spawn ticks.Ticker(5)`.

`spawn` gives a handle, which is the one thing that reaches a process.
A function gives a value and has no mailbox, so a handle to it would reach nothing.
