# L0609 — the file that a `jar` line names is no Java archive

A `jar` line names a Java archive, and this file does not open as one.

```text
package shapes
version 0.2.0
jar lib/geometry.jar sha256:4f2c000000000000000000000000000000000000000000000000000000009a1e
```

A Java archive is a zip file of classes, as the `jar` tool of the JDK writes one.
The hash of the line agrees with the file, so the file is the one that the line states.

## What to do

Name the archive that holds the classes, not another file.
The `jar` tool of the JDK writes an archive: `jar --create --file lib/geometry.jar -C classes .`.

## When it is raised

`bux build`, `bux run`, and `bux test` raise it before they write a class.
The diagnostic points at the `jar` line in `bux.package`.
A build stops at the first archive that is refused.
`docs/specs/packages.md` states the `jar` line and each refusal.
