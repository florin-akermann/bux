# L0320 — the import is read by nothing

Every name that a module introduces is read at least once, and an import is a name.

```
import io
import strings

fn main(arguments: List<String>) -> Int {
    io.println("hello")
    0
}
```

Nothing in the module writes `strings` before a dot, so the import of `strings` is refused.
An import that nothing reads tells the reader of a use that is not there.

Remove the import, or read it:

```
import io
import strings

fn main(arguments: List<String>) -> Int {
    io.println(strings.join(["hello", "world"], " "))
    0
}
```

An example is compiled in the scope of the module, with the imports of the module.
So a module name that an `// example:` line writes before a dot is a read of that import.
