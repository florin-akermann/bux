# L0323 — a file is out of the layout of its package

A package is a manifest, `bux.package`, with `src/` and `tests/` under it, and nothing else.
A module of the package is a `.bx` file at the top of `src/`.
A test module is a `.bx` file at the top of `tests/`.
A build writes the classes into `target/`, beside the manifest.

```text
shapes/
    bux.package
    src/
        circle.bx
    tests/
        rounded.bx
```

`L0323` refuses a `.bx` file beside the manifest, because no module of a package sits there.
It refuses a manifest inside `src/` or `tests/` too, because each is a part of the package above.

One layout is one thing to learn, and a reader finds each part of each package in the same place.
The compiler holds every package to it, so no package has a layout of its own.

## What to do

Move a module of the package into `src/`, and move a test module into `tests/`.
Remove a manifest that sits in `src/` or `tests/`.
A `.bx` file in no package is a bare module, and it can sit anywhere.

`docs/specs/packages.md` states the layout.
