# L0322 — a name is private to its module

A name was reached inside a module, and that module declares the name `private`.

```text
// greeting.bx
private fn opening() -> String {
    "hello, "
}
```

```text
import greeting
import io

fn main(arguments: List<String>) -> Int {
    io.println(greeting.opening())
    0
}
```

`private` goes before a function, a type, a trait, or a process.
Only the module that declares such a name reaches it, and `bux api` leaves it out.
A variant of a private type is private too, in a pattern and in a construction.

## What to do

Reach a public name of the module, or remove `private` from the declaration.
A public function states an example, so write one when you remove `private` from a function.
