# L0311 — a trait is written where a type belongs

A trait names what a type can do; it is not a type, and no value has one for its type.

```text
error[L0311]: `Eq` is a trait, not a type
```

A parameter, a field, and a result each name a type.
Writing a trait there would say a value is the ability rather than the thing that has it.

Name the type, and constrain it where it needs the trait:

```
fn has_value<T: Eq<T>>(items: List<T>, value: T) -> Bool {
    ...
}
```

A trait's name is in scope beside the types because that is where `instance Eq<Point>` and
`T: Eq<T>` write it, and nowhere else.
