# L0810 — `receive` does not take the state that `start` gives

`receive` takes the state that `start` gives, and gives `Next` of that state.

```
process Counter {
    fn start() -> Int {
        0
    }

    fn receive(total: String, message: Counted) -> Next<String> {
        ...
    }
}
```

`start` gives an `Int`, so the first state is an `Int`.
`receive` takes a `String`, so it could not take the first state.
Write one type of state as the result of `start`, the state of `receive`, and the type in `Next`.
