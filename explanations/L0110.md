# L0110: a test is written inside a body

A test is an item of its own, as a function is.
It is written at the top level of a module, below every declaration of the module.

```text
// The number two.
// example: total() == 2
fn total() -> Int {
    test "adds" {
        1 + 1 == 2
    }
    2
}
```

A body holds statements, and a test is not a statement.
`bux test` runs a test on its own, and nothing calls it, so a test in a body would never run.

Move the test out of the body, below every declaration:

```text
// The number two.
// example: total() == 2
fn total() -> Int {
    2
}

test "adds" {
    1 + 1 == 2
}
```

`docs/specs/testing.md` states where a test is written and how `bux test` runs it.
