# L0400 — the type here is not the type that was needed

Two types met where one was needed, and they are not the same type.
The message names the type the place asked for, and then the type that was written.

Two types are the same when they are declared in the same place.
Being held the same way at runtime does not make them the same.
`type UserId = UserId(Int)` makes a type of its own, so an `Int` is not a `UserId`.
The constructor is what turns one into the other.

Every branch of an `if` and every arm of a `match` has one type, and that is often where two meet.
So is a `return`, which must agree with the result the function declares.

`+` is the one operator with two types: it adds two `Int`s or joins two `String`s.
Given anything else it says that type cannot be added.
An addition still untyped once its function is inferred is an addition of `Int`s.
