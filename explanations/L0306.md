# L0306 — there is no module of that name

An import names a module, and no place the import looks in holds a file of that name.

A module is one file, named by its file, which `docs/design.md` section 16 states.
`import greeting` therefore names `greeting.bx`, and an import looks for it in these places:

- the directory the importing file sits in;
- `src/` of its package, where the importing file is a test module in `tests/`;
- `src/` of each package that its package depends on, which `docs/specs/packages.md` states.

Nowhere else is looked in, so a file that is in none of them is a missing module.
A module of `src/` never reaches a test module, and a `depends` never reaches a `tests/`.

```text
import greeting

fn main(arguments: List<String>) -> Int {
    greeting.hello()
    0
}
```

That is refused unless `greeting.bx` sits in one of those places.

`io` and `files` are library modules that the compiler carries.
An import of either looks for no file at all.
`docs/specs/io.md` lists what each one holds.

The usual cause is a name spelled differently from the file.
`Greeting.bx` is not `greeting.bx`, because a file name is read exactly as it is written.
