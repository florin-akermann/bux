# L0401 — a call passes the wrong number of arguments

A function takes the arguments its declaration lists, and a call passes exactly that many.
Lumen has no default argument, no variadic function, and no overloading, so the count is fixed.

A constructor is called the same way and counts the same way.
`Failed(String)` carries one thing, so `Failed()` and `Failed(a, b)` are both this error.
A variant that carries nothing is written as a bare name rather than called.

A written type counts the same way.
`List<T>` takes one type argument and `Result<T, E>` takes two, so `List<Int, Int>` is this error.
