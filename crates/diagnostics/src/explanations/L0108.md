# L0108 — a call names some of its arguments and not others

A call names all of its arguments or none of them.

```
rename(from: old, new)
```

The first argument says which parameter it is passed for and the second does not.
Half of the call then reads as the rule intends and half of it does not.
Written either way round it parses:

```
rename(from: old, to: new)
rename(old, new)
```

Which of the two a call may use is `L0409`'s to say.
Where the declaration gives two parameters one type, the names hold the arguments apart.

The two forms are not mixed because a half-named call says nothing a whole one does not.
A reader scanning for the parameter a value is passed for finds it at every argument or at none.
Nobody has to count the unnamed ones to know where they land.
