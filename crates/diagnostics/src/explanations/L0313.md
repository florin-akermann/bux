# L0313 — a type or a pattern is reached through something that is no module

A type was written as `x.User`, or a pattern as `x.Pending`, and `x` is not a module.

A type is a name, and a name of another module is reached through that module, exactly as a
function of it is. Nothing else is reached through a dot where a type belongs: a record has
fields and a field is a value, so there is no type to find behind one.

```text
import demo

fn shown(user: demo.User) -> String {
    user.name
}
```

`demo` is a module this file imports, so `demo.User` is the type `demo` declares as `User`.

```text
fn shown(user: holder.User) -> String {
    user.name
}
```

`holder` is no module here, so there is nothing for `holder.User` to be. Import the module the
type is declared in, or write a type this module declares.

A name that is nothing at all is `L0300` instead, because the name is looked up before it is
asked to be a module. `docs/specs/modules.md` states the rule.
