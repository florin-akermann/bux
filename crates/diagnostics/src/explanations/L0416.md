# L0416 — a function reached through a module names that module's own type

A name was reached inside a module, and the function found there names a type that module
declares.

A type is written as a bare name, and no name reaches into a module, so the importing module has
no way to write that type.

```text
// greeting.lm
type Greeting = Greeting(String)

fn greeting(name: String) -> Greeting {
    Greeting(name)
}
```

```text
// main.lm
import greeting

fn main() -> () {
    held := greeting.greeting("world")
    ()
}
```

`greeting.greeting` gives back a `Greeting`, which `main` cannot name, so reaching it is refused.

The refusal is where the function is reached rather than where it is declared.
A module builds what it likes; what it offers is what the modules importing it can name.
`docs/specs/modules.md` states the rule.

The answer in version 0.1 is a signature written in types both modules already have: `Int`,
`Bool`, `String`, and the types the prelude supplies.
