# L0107 — something other than a name is assigned to

An assignment names a name.
`counter = 1` and `counter += 1` are the whole of it, and the left of `=` is a single name.

```
fn rename(user: User) -> User {
    user.name = "Bob"
    user
}
```

`user.name` reads a value out of `user` rather than naming one, so nothing there is assignable.

A value is changed by building the one it becomes:

```
fn rename(user: User) -> User {
    user { name: "Bob" }
}
```

A record literal with a base copies the value and replaces the fields it lists.
Nothing reaches inside the original, which is what makes the result a value rather than an edit.

Where the name itself should change, assign to the name:

```
fn rename(user: User) -> User {
    var renamed = user
    renamed = renamed { name: "Bob" }
    renamed
}
```

There is then one way to change what a name holds, and none to reach inside a value.
