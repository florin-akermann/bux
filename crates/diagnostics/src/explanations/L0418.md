# L0418 — this type has no instance of the trait

A trait method is reached through an instance, and the type it is called at has none.

```text
error[L0418]: `Point` has no instance of `Eq`
```

A generic is compiled once per set of types it is used at, so the instance is settled where the
call is written rather than while the program runs.
A type with no instance leaves nothing to settle it to.

Write the instance:

```
instance Eq<Point> {
    fn is_equal(one: Point, other: Point) -> Bool {
        one.across == other.across && one.down == other.down
    }
}
```

Inside a generic function, constrain the type parameter instead, which is the promise every use of
that function is then held to:

```
fn has_value<T: Eq<T>>(items: List<T>, value: T) -> Bool {
    ...
}
```

A call at a type nothing settled is refused the same way, because there is no type to find an
instance for.
Write the type, or constrain the parameter the call is made at.
