# L0310 — this is not a trait

A trait belongs after `instance` and after the `:` of a constrained type parameter.
A type, a type parameter, or anything else written there names no methods to reach.

```text
error[L0310]: `Point` is a type, not a trait
```

`instance Eq<Point>` names the trait first and the type it is for second.
`fn holds<T: Eq<T>>` names the trait after the `:` and the type it constrains inside the `<…>`.

A trait is declared with `trait`:

```
trait Eq<T> {
    fn is_equal(one: T, other: T) -> Bool
}
```

`Eq` is the one the compiler supplies, and `docs/specs/traits.md` says what else it supplies.
