# L0308 — a trait already has an instance for this type

One trait and one type have one instance, which is what lets a constraint reach an instance
without anyone saying which one.

```text
error[L0308]: `Eq` already has an instance for `Point`
```

Two instances would leave every use of `is_equal` at a `Point` with a choice to make, and nothing in
the source to make it with.
Lumen makes that unwriteable rather than picking one.

Write the one instance, and put everything both of them did into it.

A type the compiler supplies already has the instances the library ships.
`Eq<Int>`, `Eq<Bool>`, and `Eq<String>` are there before a module writes a line, so writing one of
them again is refused here too.
