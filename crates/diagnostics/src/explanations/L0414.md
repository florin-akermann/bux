# L0414 — a supplied module declares no such name

A name was reached inside a module the compiler supplies, and the module does not declare it.

`io` and `files` are declared by the compiler rather than loaded from a file.
What each one holds is therefore fixed and known while a program is being checked.
`docs/specs/io.md` lists every name of both, and a name outside those lists is refused.

```text
import io

fn main() -> () {
    io.write("hello")
}
```

`io` declares `print` and `println`, so `write` is not a name it has.

This is not the diagnostic for a module the compiler does not supply.
What an ordinary module holds is checked once one can be loaded from a file.
Reaching inside one before then is `L0402`.
