# L0414 — a module declares no such name

A name was reached inside a module, and the module does not declare it.

`io` and `files` are declared by the compiler rather than loaded from a file.
`docs/specs/io.md` lists every name of both, and a name outside those lists is refused.

```text
import io

fn main() -> () {
    io.write("hello")
}
```

`io` declares `print` and `println`, so `write` is not a name it has.

A module loaded from a file is held to the same rule.
What it declares is every function written in it at the top level, and a name outside that is
refused here too.

```text
import greeting

fn main() -> () {
    greeting.farewell("hello")
}
```

`greeting.lm` has to declare `farewell` at the top level for that to be a name it has.
