# L0306 — there is no module of that name

An import names a module, and no file beside the importing one is written under that name.

A module is one file, named by its file, which `docs/design.md` section 16 states.
`import greeting` therefore names `greeting.lm`, in the directory the importing file sits in.
A package is the one other place: a manifest beside the importing file names the directories a
dependency's modules sit in, which `docs/specs/packages.md` states.
Nowhere else is looked in, so a file that is in neither is a missing module.

```text
import greeting

fn main() -> () {
    greeting.hello()
}
```

That is refused unless `greeting.lm` sits beside it.

The compiler supplies `io` and `files`, and an import of either looks for no file at all.
`docs/specs/io.md` lists what each one holds.

A name spelled differently from the file is the usual cause: `Greeting.lm` is not `greeting.lm`,
because a file name is read exactly as it is written.
