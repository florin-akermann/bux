# L0405 — a field is given a value twice

A record gives each of its fields one value.
Writing a field twice writes two answers to one question, and nothing says which of the two wins.

This holds for building a record and for updating one.
`user { active: true, active: false }` is this error for the same reason `User { id: 1, id: 2 }` is.

Take one of the two out.
If the second was meant to replace the first, the first was never needed.
