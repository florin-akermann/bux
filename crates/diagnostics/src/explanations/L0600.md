# L0600 — a hole is built

A hole says a body is not written yet:

```
fn total(users: List<User>) -> Int {
    todo("count them once the walk is written")
}
```

`todo` is a function the prelude supplies, and it gives back whatever type is expected of it.
So the module around it is resolved, inferred, and checked like any other.
`lumen check` accepts it.

`lumen build` refuses it.
A hole has nothing to run, so there is nothing for a build to write.

Every hole in the module is named, rather than the first one.
A build is how a reader learns what is left, and a list of one would not be that list.

## What to do

Fill the hole in, or build a module that holds none.

`lumen check` is what to run while the hole is still there.
It holds everything around the hole to the same bar as finished work.
That is what a hole is for: incompleteness that is greppable and gated, not plausible wrong code.

## The reason

The reason is written where the hole is, so the line under the message carries it.
Nothing reads it, and nothing is expected of its wording beyond what the next reader needs.
