# L0402 — a field of that name cannot be found

A field is reached through `.`, and it is looked up in the type of what it is reached through.
That type must be a record, and the record must declare a field of that name.

A field is not a name in scope.
A misspelled one is reported here rather than as an unresolved name.

The other cause is a type inference never settled.
A field access waits until the type it reaches through is known.
That happens at the end of the function the access is written in.
If nothing in that function said what the type is, write it down.
A parameter or a result with a declared type settles it.

A name inside an imported module is also reported here.
Version 0.1 brings a module into scope but has no way to reach a name inside one.
That arrives with module loading.
