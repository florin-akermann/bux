# L0316 — there is no package there

A package is a directory holding a manifest called `bux.package`, and this directory holds none.

```text
package shapes
version 0.2.0
depends ../geometry
```

`../geometry` is read against the directory this manifest sits in, and a package is expected to be
there already.
Nothing is fetched, so a dependency that is not on disk is a dependency that is not reachable.

The usual causes are a path written against the wrong directory, a directory of modules that was
never given a manifest, and a dependency that has not been put beside the package that wants it.

`lumen check` and `lumen build` each take a package as well as a file, and a directory holding no
manifest is not one.
Such a directory is reported without a code, because there is no manifest for a refusal to point
into, and the command stops there.

`docs/specs/packages.md` states what a package is and where a dependency is looked for.
