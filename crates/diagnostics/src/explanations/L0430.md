# L0430 — a `new` builds a class, and this one is an interface

An `extern type` says which kind of class a Java name is.
The compiler reads no class file, so it cannot find that out for itself.

```text
extern type interface Path = "java.nio.file.Path"

extern new opened(text: String) -> Path
```

A constructor is the member an interface has none of.
There is nothing for this `new` to call, and the JVM would refuse to link the class file.
That is a failure with no diagnostic in front of it, so the declaration is refused here instead.

An interface is reached for a value that already exists rather than for a new one.
The answer is a member of a class that gives one back:

```text
extern type File = "java.io.File"

extern new named(text: String) -> File

extern method to_path(file: File) -> Path = "toPath"
```

A `method` and a `field` are each written on an interface as they are written on a class.
The word changes how a `method` is called, and it changes nothing else.

`docs/specs/interop.md` states what an `extern type` says and what it changes.
