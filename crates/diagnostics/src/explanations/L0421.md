# L0421 — a bound of an `IntegerLiteral` instance is not one whole number

`lowest` and `highest` say which whole numbers a type holds, and the compiler reads them rather
than running them, which `docs/specs/literals.md` states.

```text
error[L0421]: `lowest` of `Int32` is read rather than run, so it is one whole number
```

So each of the two bodies is one whole number and nothing else, optionally with a `-` in front:

```text
fn lowest() -> Int {
    -2147483648
}
```

A call, an addition, or a name is refused here, however plainly it would read.
A literal that does not fit its type is a compile error, and a compile error is settled before
anything runs; nothing in the language is evaluated while it is being compiled.

No other method is read this way. `from_literal` is an ordinary body, and so is every method of
every other trait.
