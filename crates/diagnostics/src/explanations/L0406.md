# L0406 — a comparison is written between two values of a type that has no `Eq`

`==` and `!=` compare two values of one type, and only a type that has `Eq` can be compared.
A type has `Eq` by deriving it, which version 0.2 adds; version 0.1 ships three instances.

```text
error[L0406]: `User` has no `Eq`, so two of them cannot be compared
```

`Int`, `Bool`, and `String` have `Eq`, and every other type does not yet.
Compare what the values hold instead: `left.id == right.id`, where `id` is an `Int`.

Nothing is equal by being the same object, because a Lumen value has no identity to be equal by.
Two values are equal by what they hold, and only where their type says so.
