# L0200 — the file is not in canonical form

There is exactly one canonical text for every Lumen program.
`docs/design.md` section 13 makes source that is not in it a compile error.
`docs/specs/formatting.md` states that form construct by construct.

The three ways a file departs from it share this code, because they share one answer.
A line may be written differently, a line may not belong at all, or the file may end wrongly.

Run `lumen fmt <file>`.
The formatter has no options, so no diff is ever a formatting diff.
No two authors disagree about layout.
